# GeoPortal-EOT-Argelia-Valle-del-Cauca
Geoportal Territorial Pro – Argelia, Valle 🗺️ WebGIS de diagnóstico espacial en tiempo real. Integra Leaflet JS con PostgreSQL/PostGIS (Supabase) para calcular cruces catastrales y coberturas ambientales (WGS84) mediante PL/pgSQL. Incluye buscador, reportes PDF y exportación GeoJSON. 100% responsivo.
